# Wallpaper pane

Inventory items ST-WLP-01, ST-WLP-02 and ST-SSV-01. Light captured.

## Pane

| Item | Value |
| --- | --- |
| Current wallpaper card | preview **160 × 100**, a fill-mode pop-up, a switch to use it on all spaces |
| Display pop-up | which display the choice applies to |
| Buttons | screen saver, clock appearance |
| Categories | one horizontal row per category of thumbnails **109 × 101**, each row with a "show all (n)" button |

- One category is plain colours; the reference sessions used a solid `#7a7b80` from it.

## Screen saver sheet (ST-SSV-01)

| Item | Value |
| --- | --- |
| Sheet | **500 × 548** |
| Top | a 160 × 100 preview of the selected saver |
| Controls | a start-after pop-up (default 20 minutes), automatic / custom radio buttons |
| List | scrolling rows of 109 × 101 thumbnails by category, each with "show all" |

The saver itself was not started (*unmeasured*).
