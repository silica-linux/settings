# Keyboard pane

Inventory items ST-KBD-01 to ST-KBD-14. Light captured.

## Pane

1. Key repeat rate slider and delay-until-repeat slider.
2. A pop-up for what the function / globe key does alone.
3. Keyboard navigation switch.
4. A keyboard shortcuts button (opens the sheet below).
5. Text input: input sources (with an edit button) and text replacements.
6. Dictation: a switch, then language, microphone and shortcut pop-ups.
7. A set-up-keyboard button.

Values read on the reference machine: repeat rate at step 6 of the slider, delay at step 4
(the slider does not expose milliseconds, so the timing is *unmeasured*); the globe key
does nothing on its own.

that carry a key combination, described in our own words. Silica maps ⌘ to the Logo key
and replaces the fn-based window shortcuts with its own; the list is the inventory of
actions to cover, not of key bindings to copy. "off" marks entries disabled by default.
